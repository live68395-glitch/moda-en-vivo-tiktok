# Moda en Vivo para TikTok

Tienda demostrativa de moda para transmisiones LIVE, ubicada en Trinidad, Beni, Bolivia.

## Demo

- Catálogo, carrito y reserva temporal de productos.
- Flujo de pago QR y pedidos simulados.
- Vista adaptable a móviles.

Los videos, pedidos y pagos son ficticios. No se procesan transacciones reales.

## Paneles

Este repositorio corresponde al panel de clientes. El panel administrativo y su inicio de sesión se mantendrán en el repositorio privado del proyecto.
